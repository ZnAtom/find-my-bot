# 登录与账号说明

## 为什么需要登录

发布寻物信息、填写联系方式、提交认领或联系申请、查看个人记录、接收通知等操作需要登录。

登录用于确认校园用户身份，并保护个人记录和联系方式。

## 未登录可以做什么

未登录用户可以浏览物品库、搜索公开信息、发布匿名招领信息、上传图片并使用图片识别辅助填写、使用基础客服问答。

未登录用户不能发布寻物信息，不能填写匿名招领联系方式，不能查看个人发布和申请记录。

## 登录后可以做什么

登录后可以发布寻物和实名招领信息，填写自己的联系方式，提交认领或联系申请，查看个人中心、通知、发布记录和申请记录。

## 登录失败怎么办

如果登录后仍回到未登录状态，优先检查访问地址是否和登录回调地址一致。例如本地开发通常使用前端地址访问，而不是直接访问后端地址。

如果跨设备访问，需要把前端地址、后端代理地址、Casdoor 回调地址、CORS 和 CSRF 白名单配置为同一套可访问域名或 IP。通过 nginx 无端口访问时，来源通常是 `http://你的域名` 或 `http://你的局域网 IP`，不是旧的 `:5173` 地址。

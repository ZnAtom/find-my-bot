# 管理与运营说明

## 管理员能力

管理员可以进入管理页面查看用户和物品数据，调整用户角色，查看认领申请，发送系统通知，并处理异常数据。

管理员操作应遵循最小必要原则，不应在公开渠道转发用户联系方式或完整身份信息。

## 物品状态

物品状态包括进行中、已找回和已过期。进行中的物品会出现在主要搜索和匹配范围内。已找回或已过期物品通常只作为历史记录查看。

## 通知机制

系统通知用于提醒用户认领申请、联系申请、系统公告等事件。用户登录后可以在页面顶部查看通知。

## 知识库维护

客服知识库来自 `doc/support` 目录下的 Markdown 文件。当前本地配置默认启用自动同步：执行 `bash dev-local.sh start`、`bash dev-local.sh restart` 或 `bash dev-local.sh db` 时，会把最新 Markdown 增量同步进数据库。

如果需要立即强制刷新，可以运行：

```bash
bash dev-local.sh support-import
```

导入逻辑会比较文件内容哈希；内容未变化且 embedding 不缺失时会跳过，不需要每次手动重导入。

推荐先维护 FAQ、用户使用指南、搜索指南、隐私规则和登录说明，再逐步补充更多运营规则。

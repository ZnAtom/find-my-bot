# 搜索与匹配指南

## 搜索适合输入什么

搜索时优先输入物品本身的特征，不要只输入地点。适合输入的内容包括物品名称、分类、颜色、品牌、型号、外观、特殊标记、配件或包装。

例子：校园一卡通、黑色双肩包、白色保温杯、银色 AirPods、蓝色雨伞、线性代数教材。

## 搜索算法如何工作

平台第一阶段使用关键词召回和语义向量检索的混合方案。关键词检索适合精确名称、常见别名和短词匹配。语义向量检索适合描述相近但用词不同的情况。

本地开发或向量模型未启用时，搜索会退回关键词检索，不影响基础搜索功能。

当前常见别名扩展包括“校园卡 / 一卡通 / 学生卡”和“学生证 / 证件 / 证件卡片”等。

## 客服如何搜索失物

客服会根据用户问题判断是否需要搜索物品库。搜索结果只提供脱敏摘要，例如物品编号、名称、方向、状态、分类、描述摘要和详情页入口。

客服物品查询会使用和语义搜索同类的混合检索。只要找到相似物品，客服会列出候选，并说明这些只是相似线索，不能确认归属。

客服不会直接返回手机号、QQ、邮箱、学号、证件号、二维码内容、条形码内容或完整个人身份信息。

## 搜索结果太多或太少怎么办

结果太多时，补充颜色、品牌、型号或特殊标记。结果太少时，换用常见别名，例如“校园卡”“一卡通”“学生卡”。

如果仍然无法定位，可以发布寻物或招领信息，让后续用户通过物品库发现。

# 用户使用指南

## 浏览物品库

进入物品库可以查看当前进行中的寻物和招领信息。用户可以按发布方向、物品分类、状态等条件筛选。

物品详情页会展示物品名称、分类、描述、图片、可能的地点、发布时间和当前状态。联系方式会按平台隐私规则控制展示。

## 发布寻物信息

发布寻物信息表示用户丢失了物品，希望找回。发布寻物信息需要先登录。

发布时建议填写物品名称、分类、丢失地点、丢失时间、详细描述和至少一种联系方式。描述越具体，越容易被搜索和匹配。

## 发布招领信息

发布招领信息表示用户捡到了物品，希望寻找失主。未登录用户可以匿名发布招领信息，但匿名招领不能填写联系方式。

发布招领信息需要填写当前存放处，便于平台后续处理。实名招领可以填写联系方式，但联系方式是否展示由可见性设置和平台流程决定。

## 使用图片识别辅助填写

在发布页面上传图片后，可以使用图片识别生成物品名称、分类和描述草稿。系统会根据图片中的可见特征生成简短说明。

用户提交前应检查识别结果，删除不准确或不希望公开的信息。

## 提交认领或联系申请

如果看到疑似自己的物品，应登录后进入详情页提交认领申请。如果看到疑似能帮助他人的寻物信息，也可以提交联系申请。

申请提交后，平台会生成记录并发送通知。线下交接前应核对物品细节，避免误领。

## 查看个人记录

登录后可以进入个人中心查看自己的发布记录、申请记录和通知。个人数据只对当前登录用户开放。
